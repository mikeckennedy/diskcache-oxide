## NullCache.pull()


Return `default` (widened as [Cache.pull](Cache.pull.md#diskcache_oxide.Cache.pull) widens it): the queue is always empty. Never forwarded


Usage

``` python
NullCache.pull(
    prefix=None,
    default=(None, None),
    side="front",
    *,
    expire_time=False,
    tag=False,
    retry=False
)
```


to `invalidate=`, which a switched-off cache must not consume.
