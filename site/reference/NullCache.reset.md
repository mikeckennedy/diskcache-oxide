## NullCache.reset()


Read [size_limit](Cache.size_limit.md#diskcache_oxide.Cache.size_limit) or [cull_limit](Cache.cull_limit.md#diskcache_oxide.Cache.cull_limit), or set it (checked as [Cache](Cache.md#diskcache_oxide.Cache) checks it) and return it.


Usage

``` python
NullCache.reset(
    key,
    value=ENOVAL,
    update=True,
)
```
