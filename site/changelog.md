# v0.2.3

*2026-11-12* · [GitHub](https://github.com/mikeckennedy/diskcache-oxide/releases/tag/v0.2.3)

**Delete your caches when you upgrade.** This release changes the on-disk format (format 3, for tags and the eviction policy). Opening a cache made by 0.1.2 raises [FormatMismatchError](reference/FormatMismatchError.html#diskcache_oxide.FormatMismatchError), naming the database: stop every process using the cache, delete its directory (a FanoutCache's whole root, never one shard), and it's recreated empty on the next open. 0.1.2 refuses a format-3 cache the same way, and neither version writes anything into the other's. A 0.1.2 worker still running when its cache is deleted and recreated can't change the new one either: once it opens the new file, its writes, deletes and maintenance calls fail with "no such table" (only a [touch](reference/Cache.touch.html#diskcache_oxide.Cache.touch) gets through), because format 3 renames the table they all use.


### Added

- Keys of every native type: `bytes`, `int` (64-bit), `float`, `bool`, `None`, and tuples of those, nested up to 32 deep, beside `str`. They're never pickled and compare by exact type, so `1`, `1.0` and `True` are three keys. [iterkeys()](reference/Cache.iterkeys.html#diskcache_oxide.Cache.iterkeys) lists `str` keys first, then the other types in a fixed order; `iterkeys(prefix=...)` lists `str` keys only. A FanoutCache routes every key type. Type checkers see `diskcache_oxide.Key`.
- `memoize(name=None, typed=False, expire=None, tag=None, ignore=())` on [Cache](reference/Cache.html#diskcache_oxide.Cache), [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache) and [NullCache](reference/NullCache.html#diskcache_oxide.NullCache), as diskcache's, with the same keys, so `f.__cache_key__(...)` returns the tuple diskcache would. Every argument must be a key type, checked before the function runs; `typed=True` stores type names. `Memoized` and `Memoizer` type the wrapper.
- `CorruptKeyError`, a [CorruptValueError](reference/CorruptValueError.html#diskcache_oxide.CorruptValueError), raised by iteration that meets a stored key it can't read (a damaged page or file); it never skips one.
- `reversed(cache)`, `pop(key, expire_time=True)`, a read-only [durable](reference/Cache.durable.html#diskcache_oxide.Cache.durable) attribute, and `reset(key, value)` to read or persist [size_limit](reference/Cache.size_limit.html#diskcache_oxide.Cache.size_limit), [cull_limit](reference/Cache.cull_limit.html#diskcache_oxide.Cache.cull_limit) and [eviction_policy](reference/Cache.eviction_policy.html#diskcache_oxide.Cache.eviction_policy) (a [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache) splits a [size_limit](reference/Cache.size_limit.html#diskcache_oxide.Cache.size_limit) total across its shards), on [Cache](reference/Cache.html#diskcache_oxide.Cache), [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache) and [NullCache](reference/NullCache.html#diskcache_oxide.NullCache).
- Pickling a [Cache](reference/Cache.html#diskcache_oxide.Cache) or [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache): it reopens the directory with the options the handle was opened with, in another process too. A `TypeRegistry` pickles (the global one by reference).
- `stats(enable=True, reset=False)`: hit and miss counts of [get](reference/Cache.get.html#diskcache_oxide.Cache.get), per process and in memory, so a [get](reference/Cache.get.html#diskcache_oxide.Cache.get) never writes.
- `check(fix=False, retry=False)`: the database and value files against each other, as diskcache's, in short steps; `fix=True` removes entries whose files are missing or cut short and old orphan files, sweeps empty folders, corrects the totals and `VACUUM`s. `UnknownFileWarning` and `EmptyDirWarning`.
- The coordination recipes `Lock`, `RLock`, `BoundedSemaphore`, `Averager`, `throttle`, `barrier` and `memoize_stampede`, as diskcache's, refusing a [NullCache](reference/NullCache.html#diskcache_oxide.NullCache) or `durable=True` cache, with `throttle`'s two diskcache bugs fixed. See the new Coordination guide page.
- Tags: `tag=` (keyword-only) on [set](reference/Cache.set.html#diskcache_oxide.Cache.set) and [add](reference/Cache.add.html#diskcache_oxide.Cache.add), any key type, compared by exact type, and `tag=True` on [get](reference/Cache.get.html#diskcache_oxide.Cache.get) and [pop](reference/Cache.pop.html#diskcache_oxide.Cache.pop), returning diskcache's `(value, tag)` and `(value, expire_time, tag)` tuples. `evict(tag, *, timeout=None, retry=False)` on [Cache](reference/Cache.html#diskcache_oxide.Cache), [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache) and [NullCache](reference/NullCache.html#diskcache_oxide.NullCache) removes every entry with that tag stored before the call, in chunks like [clear()](reference/Cache.clear.html#diskcache_oxide.Cache.clear). `memoize(tag=...)` and the recipes' `tag=` tag what they store. An overwrite without `tag=` leaves the entry untagged; [add](reference/Cache.add.html#diskcache_oxide.Cache.add) on a live key, [touch](reference/Cache.touch.html#diskcache_oxide.Cache.touch) and [incr](reference/Cache.incr.html#diskcache_oxide.Cache.incr) keep its tag.
- `eviction_policy='least-recently-stored'` (the default) or `'none'` on [Cache](reference/Cache.html#diskcache_oxide.Cache) and [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache), stored in the cache and read inside every write, so a change from one process applies to all at their next write. Under `'none'` nothing is evicted for size, expired entries are still removed, and [cull()](reference/Cache.cull.html#diskcache_oxide.Cache.cull) returns how many it removed. `'least-recently-used'` and `'least-frequently-used'` raise `ValueError`. A read-only [eviction_policy](reference/Cache.eviction_policy.html#diskcache_oxide.Cache.eviction_policy) attribute.
- The queue calls [push](reference/Cache.push.html#diskcache_oxide.Cache.push), [pull](reference/Cache.pull.html#diskcache_oxide.Cache.pull), [peek](reference/Cache.peek.html#diskcache_oxide.Cache.peek) and [peekitem](reference/Cache.peekitem.html#diskcache_oxide.Cache.peekitem) on [Cache](reference/Cache.html#diskcache_oxide.Cache) and [NullCache](reference/NullCache.html#diskcache_oxide.NullCache), with diskcache's signatures and return shapes (`expire_time=`, `tag=`, `retry=` keyword-only). Each item goes to exactly one puller across every process; [pull](reference/Cache.pull.html#diskcache_oxide.Cache.pull) decodes before it deletes, so an item this process can't read stays queued; [peek](reference/Cache.peek.html#diskcache_oxide.Cache.peek) and [peekitem](reference/Cache.peekitem.html#diskcache_oxide.Cache.peekitem) never write. A queue's items are only keys of its exact shape, and [push](reference/Cache.push.html#diskcache_oxide.Cache.push) raises `OverflowError` rather than overwrite a key. See the new Work queues recipe.
- `ENOVAL` and `UNKNOWN`, diskcache's sentinels.
- `retry=True` (keyword-only) on [get](reference/Cache.get.html#diskcache_oxide.Cache.get), [set](reference/Cache.set.html#diskcache_oxide.Cache.set), [add](reference/Cache.add.html#diskcache_oxide.Cache.add), [delete](reference/Cache.delete.html#diskcache_oxide.Cache.delete), [pop](reference/Cache.pop.html#diskcache_oxide.Cache.pop), [touch](reference/Cache.touch.html#diskcache_oxide.Cache.touch), [incr](reference/Cache.incr.html#diskcache_oxide.Cache.incr), [decr](reference/Cache.decr.html#diskcache_oxide.Cache.decr), [expire](reference/Cache.expire.html#diskcache_oxide.Cache.expire), [cull](reference/Cache.cull.html#diskcache_oxide.Cache.cull), [clear](reference/Cache.clear.html#diskcache_oxide.Cache.clear) and [evict](reference/Cache.evict.html#diskcache_oxide.Cache.evict): this cache's own [Timeout](reference/Timeout.html#diskcache_oxide.Timeout) is retried until the call gets through, even on a `durable=True` handle; one raised by your code (a hook, a `clock`) is not. A retried [expire](reference/Cache.expire.html#diskcache_oxide.Cache.expire), [cull](reference/Cache.cull.html#diskcache_oxide.Cache.cull), [clear](reference/Cache.clear.html#diskcache_oxide.Cache.clear) or [evict](reference/Cache.evict.html#diskcache_oxide.Cache.evict) returns everything it removed.


### Changed

- Iterating a cache is typed `Iterator[Key]` rather than `Iterator[str]`, since keys can now be other types; `iterkeys(prefix=...)` is still `Iterator[str]`. Type-checked code that treats every iterated key as a `str` needs a narrowing (`isinstance(key, str)`).
- The `TypeError` for a key of the wrong type now names the types that are accepted.
- [TransactionalCacheLike](reference/TransactionalCacheLike.html#diskcache_oxide.TransactionalCacheLike) gained [push](reference/Cache.push.html#diskcache_oxide.Cache.push), [pull](reference/Cache.pull.html#diskcache_oxide.Cache.pull), [peek](reference/Cache.peek.html#diskcache_oxide.Cache.peek) and [peekitem](reference/Cache.peekitem.html#diskcache_oxide.Cache.peekitem) (not [CacheLike](reference/CacheLike.html#diskcache_oxide.CacheLike): [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache) has no queue calls).
- [CacheLike](reference/CacheLike.html#diskcache_oxide.CacheLike) gained [memoize](reference/Cache.memoize.html#diskcache_oxide.Cache.memoize), [stats](reference/Cache.stats.html#diskcache_oxide.Cache.stats), [check](reference/Cache.check.html#diskcache_oxide.Cache.check), [reset](reference/Cache.reset.html#diskcache_oxide.Cache.reset), [evict](reference/Cache.evict.html#diskcache_oxide.Cache.evict), [durable](reference/Cache.durable.html#diskcache_oxide.Cache.durable), [eviction_policy](reference/Cache.eviction_policy.html#diskcache_oxide.Cache.eviction_policy) and [__reversed__](reference/Cache.__reversed__.html#diskcache_oxide.Cache.__reversed__), [get](reference/Cache.get.html#diskcache_oxide.Cache.get) and [pop](reference/Cache.pop.html#diskcache_oxide.Cache.pop) their `tag=` (and [pop](reference/Cache.pop.html#diskcache_oxide.Cache.pop) its `expire_time=`), and [set](reference/Cache.set.html#diskcache_oxide.Cache.set) and [add](reference/Cache.add.html#diskcache_oxide.Cache.add) theirs; a fake typed against it needs them too.
- `transact(retry=True)` sleeps between attempts instead of retrying at once, so a `timeout=0` cache doesn't spin.


# v0.1.2

*2026-11-09* · [GitHub](https://github.com/mikeckennedy/diskcache-oxide/releases/tag/v0.1.2)

The first release: diskcache's [Cache](reference/Cache.html#diskcache_oxide.Cache) API on a Rust engine and SQLite storage, shared safely by threads, processes and `fork()`, on CPython 3.14 and 3.15 including the free-threaded builds. Wheels for macOS on Apple Silicon and Linux (glibc) on x86_64 and aarch64.


### Added

- [Cache](reference/Cache.html#diskcache_oxide.Cache), API compatible with diskcache 5.6.3's [Cache](reference/Cache.html#diskcache_oxide.Cache): [get](reference/Cache.get.html#diskcache_oxide.Cache.get), [set](reference/Cache.set.html#diskcache_oxide.Cache.set), [add](reference/Cache.add.html#diskcache_oxide.Cache.add), [incr](reference/Cache.incr.html#diskcache_oxide.Cache.incr)/[decr](reference/Cache.decr.html#diskcache_oxide.Cache.decr), [pop](reference/Cache.pop.html#diskcache_oxide.Cache.pop), [delete](reference/Cache.delete.html#diskcache_oxide.Cache.delete), [touch](reference/Cache.touch.html#diskcache_oxide.Cache.touch), [expire](reference/Cache.expire.html#diskcache_oxide.Cache.expire), [cull](reference/Cache.cull.html#diskcache_oxide.Cache.cull), [clear](reference/Cache.clear.html#diskcache_oxide.Cache.clear), [iterkeys](reference/Cache.iterkeys.html#diskcache_oxide.Cache.iterkeys), `len`, [volume](reference/Cache.volume.html#diskcache_oxide.Cache.volume), size limits with least-recently-stored eviction, and the mapping methods. It passes a conformance suite run against diskcache itself, apart from the [documented divergences](https://mkennedy.codes/docs/diskcache-oxide/user-guide/divergences.html).
- [FanoutCache](reference/FanoutCache.html#diskcache_oxide.FanoutCache), which shards keys over several databases so many writing processes don't queue on one write lock.
- [transact()](reference/Cache.transact.html#diskcache_oxide.Cache.transact) on both, which lands several writes together or none of them, with [TransactionBusy](reference/TransactionBusy.html#diskcache_oxide.TransactionBusy) and `TransactionAborted`.
- Values stored as msgpack (the default) or JSON, with exact type tags for tuples, sets, datetimes, big ints and NaN. A value that can't round-trip exactly raises `TypeError` at [set()](reference/Cache.set.html#diskcache_oxide.Cache.set). `register_type()` stores your own types and a library's without pickle, a dataclass with only a name; `pickle=True` is opt-in per cache, and a cache without it never unpickles.
- `durable=True`, which answers an outage (a busy lock, a full disk) as a miss and logs it at most once a minute, and `on_decode_error=` for values that can't be read.
- [NullCache](reference/NullCache.html#diskcache_oxide.NullCache), which turns caching off without changing call sites, and [Caches](reference/Caches.html#diskcache_oxide.Caches), a registry that names an app's caches, opens each on first use and hands out a [NullCache](reference/NullCache.html#diskcache_oxide.NullCache) while one can't open.
- Fork safety: a process-wide fork barrier so no child is born holding half a transaction, and caches that keep working in the child.
- Bounded resources: at most `max_connections` SQLite connections per cache directory, a page cache per connection, a write-ahead log that trims itself back to half of `wal_size_limit`, and [checkpoint()](reference/Cache.checkpoint.html#diskcache_oxide.Cache.checkpoint).
- [CacheLike](reference/CacheLike.html#diskcache_oxide.CacheLike), [TransactionalCacheLike](reference/TransactionalCacheLike.html#diskcache_oxide.TransactionalCacheLike) and [ShardedCacheLike](reference/ShardedCacheLike.html#diskcache_oxide.ShardedCacheLike) protocols, `py.typed`, and full docstrings in the stubs.
- A bundled SQLite ([sqlite_version()](reference/sqlite_version.html#diskcache_oxide.sqlite_version), [sqlite_compile_options()](reference/sqlite_compile_options.html#diskcache_oxide.sqlite_compile_options)), so the system's version doesn't matter.
- Documentation: a user guide, recipes, an errors page, an API reference, an agent skill and `llms.txt`, at <https://mkennedy.codes/docs/diskcache-oxide/>.


### Differences from diskcache

- Not data compatible: data lives in `diskcache-oxide.sqlite`, and diskcache's `cache.db` is never opened or converted, so a switched app starts cold.
- Keys are `str` only, [directory](reference/Cache.directory.html#diskcache_oxide.Cache.directory) is required, [size_limit](reference/Cache.size_limit.html#diskcache_oxide.Cache.size_limit) must be at least 1 MiB, new cache directories are owner-only (`0700`), [Timeout](reference/Timeout.html#diskcache_oxide.Timeout) is a `TimeoutError`, and `bool(cache)` is always True.
- [clear()](reference/Cache.clear.html#diskcache_oxide.Cache.clear) keeps writes that land while it runs, [expire()](reference/Cache.expire.html#diskcache_oxide.Cache.expire) removes every expired entry, and a read during an overwrite never misses. Each is a diskcache bug, with a standalone repro in the repository's `upstream/` folder.


### Not yet

[memoize](reference/Cache.memoize.html#diskcache_oxide.Cache.memoize), tags, `AsyncCache`, `Deque` and `Index`, keys other than `str`, `disk=`, other eviction policies, the coordination recipes (locks, semaphores, throttles), and Windows. See the [roadmap](https://mkennedy.codes/docs/diskcache-oxide/user-guide/roadmap.html).

Development before this release, including the `0.1.0.dev` builds (`0.1.0.dev1` was yanked from PyPI), is in the git history. A `0.1.0` and a `0.1.1` were built and verified but never published: new tests found two bugs just before the first upload and a third (a size-limited cache evicting entries it had room for) just before the second, each fixed first, so `0.1.2` is the first release on PyPI. `0.1.1` ran in production at Talk Python in the meantime. The `0.0.1` on PyPI is a name placeholder with no code.
